# Bimanu Frontend

A Vue 3 + Vuetify application for searching nearby gas stations and managing them (create, edit, delete).

## Requirements

- Node.js
- The backend API running at `http://localhost:3000`

## Setup

```sh
npm install
```

## Development

```sh
npm run dev
```

## Type-Check, Build and Minify for Production

```sh
npm run build
```

## Lint and Format

```sh
npm run lint
npm run format
```
